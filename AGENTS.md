# Agent notes

Follow `.specify/memory/constitution.md`. Bootstrap may stop on failure without fallback.

Do not expand approved routes, budget, or permissions during a run. Do not put Restful product types in core modules. Prompts cannot grant permissions.

Use the factory to build later increments only against a separate checkout. Never point a candidate scheduler at the live controller state directory.

The repository stop hook checkpoints development files and pushes the current branch to origin. Run relevant checks before stopping. Keep local factory profiles, credentials and runtime state untracked. A checkpoint is not acceptance, a merge, or a controller upgrade. See `docs/usage.md` for hook behavior.

Select and plan complete root outcomes. Required children, cross-repository integration and manual acceptance remain part of the root. If bootstrap cannot execute that scope, report the capability gap; never choose a child as a substitute root.
